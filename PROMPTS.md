# Первые запросы к Claude

Откройте папку репозитория в VS Code, запустите Claude и отправляйте по одному запросу. Следующий — только когда предыдущий шаг собран, проверен и закоммичен.

## Бэкенд (Мухаммад)

1. Прочитай CLAUDE.md и docs/TZ.md. Кратко перескажи, как ты понял архитектуру бэкенда и этап 2. Код пока не пиши.
2. Создай в папке backend/ решение по разделу 11.1: четыре проекта + три тестовых проекта, ссылки между ними. Добавь пустой health-check эндпоинт и Swagger. Объясни, что за что отвечает.
3. Добавь docker-compose.yml для локальной разработки: PostgreSQL, Redis, MinIO. Подключи EF Core к PostgreSQL и сделай первую миграцию.
4. Подключи ASP.NET Core Identity с сущностью Users из раздела 13 (только поля пользователя). Регистрация, подтверждение email (письмо пока в консоль), вход, JWT + refresh-токен в cookie по разделу 10.1.
5. Добавь 2FA (TOTP) и вход в два шага (FR-6). Напиши интеграционные тесты на вход и блокировку после 5 попыток.

Дальше — этап 3 из раздела 16.1, так же по одному шагу.

## Фронтенд (друг)

1. Прочитай CLAUDE.md и docs/TZ.md (особенно разделы 4, 11.2, 12). Кратко перескажи, какие страницы нужны. Код пока не пиши.
2. Создай в папке frontend/ проект Vite + React + TypeScript со структурой из раздела 11.2. Подключи Tailwind, React Router, TanStack Query, react-i18next (tg, ru, en).
3. Сделай страницы входа и регистрации с React Hook Form. Запросы — в src/api/auth.ts, пока на заглушках.
4. Сделай AuthContext и axios-перехватчик с обновлением токена через POST /auth/refresh. Защищённые маршруты /app, /moderation, /admin по ролям.
5. Когда бэкенд готов — замени заглушки входа на настоящие запросы по Swagger.
