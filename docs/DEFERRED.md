# Отложенные задачи

## Этап 2: проверка видео на VPS (отложено до покупки сервера)

На этапе 2 LiveKit поднимается локально в Docker (dev-режим): проверяем выдачу токенов и подключение к комнате.

Отложено, пока нет VPS (бюджет на серверы — открытый вопрос, раздел 16.3 ТЗ):

- [ ] Поднять LiveKit + TURN на VPS (порт 443/TLS).
- [ ] Проверить звонок через мобильных операторов (раздел 16.1, этап 2; риск из раздела 16.2).
- [ ] Проверить звонок при заблокированном UDP (критерий приёмки раздела 15).
